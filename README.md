#  Le Dico Intégral des Jeunes - Version Clash Flavie buranet

Un dictionnaire interactif complet (de A à Z) pour enfin comprendre le jargon de la Gen Z et de la Gen Alpha, sans avoir à subir le regard vide de vos enfants. 

L'application intègre **Flavie buranet**, un avatar d'ado pubère et blasé codé en CSS pur, doté d'une IA de poche programmée pour vous envoyer des scuds mémorables sur votre âge, vos rhumatismes et votre compte CPF à chaque clic.

## ✨ Fonctionnalités
* 📚 **Alphabet complet de A à Z** : Toutes les expressions décodées (de *Apanyae* à *Zarbi*, sans oublier les mystérieux *Xénomorphe* et *Yeet*).
* 🔎 **Recherche dynamique globale** : Filtrez les mots en temps réel.
* 🤬 **Moteur de Punchlines "Baffie Style"** : Plus vous cherchez à comprendre les jeunes, plus le script vous rappelle que vous êtes un fossile.
* 🎨 **Interface Responsive & Fluide** : Animations CSS pour l'avatar (mode "tchat sur Snap" pendant la saisie).
* ⚡ **Zéro dépendance** : Du pur HTML5, CSS3 et Vanilla JavaScript. Pas de framework lourd (contrairement à vos articulations).
